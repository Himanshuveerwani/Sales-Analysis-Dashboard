# 📊 Sales Analytics Dashboard (Power BI + Python)


📌 Project Overview

This project is a Sales Analyst Dashboard created using Python (Pandas) and Power BI. 
The main objective of this project is to clean the data, 
analyze it, and present useful insights through an interactive dashboard.

🛠️ Tools & Technologies

- Python
- Pandas
- Power BI
- Power Query

🔄 Project Workflow

1. Data Cleaning using Pandas
   
   - Loaded the dataset using Python.
   - Checked for missing values and duplicate records.
   - Cleaned and prepared the data for analysis.

2. Data Import into Power BI
   
   - Imported the cleaned dataset into Power BI.
   - Used Power Query to transform and prepare the data further.

3. Data Checking & Validation
   
   - Checked the data after transformation.
   - Verified that the required fields and values were correctly prepared for the dashboard.

4. Dashboard Creation
   
   - Created an interactive Sales Analyst Dashboard in Power BI.
   - Used Cards to display important summary values.
   - Added charts and visualizations to understand sales data.
   - Added slicers for interactive filtering.

## 🎯 Objective
Understand sales performance from 2022 to 2025 and answer business questions such as:
- Which product categories bring the most sales and profit?
- Which regions and sales channels perform best?
- Which customer segments contribute the most revenue?
- How healthy is order fulfilment (completed vs returned vs cancelled)?

## 🔍 Key Insights
- **Electronics** is the top category in both sales and profit.
- Sales dipped slightly in 2024, then grew sharply in 2025.
- **Online** is the leading channel (~37.8% of sales), followed by Retail Store (~29.7%).
- **Consumer** segment contributes the most revenue (~44.5%).
- About **64%** of orders are completed; the rest are shipped, processing, returned or cancelled.
- Overall profit margin is roughly **20%** (1.65M / 8.23M).

## 💡 Recommendations
- Focus marketing and inventory on Electronics and the Online channel.
- Investigate the 2024 dip (seasonality, pricing, stock issues).
- Reduce returns and cancellations to improve profit.
- Grow the New Customer and Premium segments, which are currently small.
